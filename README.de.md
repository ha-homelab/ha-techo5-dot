# HA · TECHO5 Dot

**Pilotvorbereitung. Noch keine Firmware installiert.**

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Ein Echo Dot 2 ist über EchoMuse/emOS erreichbar, der zweite ist offline. Ein USB-Wartungszugang fehlt derzeit. Home Assistant und die laufende Firmware wurden nicht geändert. Zielversion: **TECHO5 Dot v1.0.34**.

Das vorhandene Modell für «Привет, Мышка» verwendet ONNX und lässt sich nicht einfach als microWakeWord-Modell übernehmen. Alte vollständige Alexa-Sicherungen wurden bewusst gelöscht. Vor dem Pilotversuch müssen ein unterstützter Migrationsweg und die dafür erforderlichen Wiederherstellungsdateien feststehen.

Ausführliche Anleitungen sind derzeit auf Englisch: [Status](docs/status.md), [Migration](docs/migration.md), [Wake Word](docs/wake-word.md), [Home Assistant](docs/home-assistant.md), [Abnahme](docs/acceptance.md).
