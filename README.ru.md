# HA · TECHO5 Dot

**Подготовка пилота. Прошивка не установлена.**

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Одна Echo Dot 2 доступна через EchoMuse/emOS, вторая отключена. USB-подключения для обслуживания пока нет. Настройки Home Assistant и прошивка не изменялись. Целевая версия — **TECHO5 Dot v1.0.34**.

Текущая модель «Привет, Мышка» использует ONNX; её нельзя просто скопировать в microWakeWord. Полные старые резервные копии Alexa удалены намеренно. Перед пилотом нужно подтвердить поддерживаемый переход и необходимые именно для него материалы восстановления.

Подробные руководства пока на английском: [статус](docs/status.md), [переход](docs/migration.md), [wake word](docs/wake-word.md), [Home Assistant](docs/home-assistant.md), [проверки](docs/acceptance.md).
