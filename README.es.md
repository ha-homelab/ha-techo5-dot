# HA · TECHO5 Dot

**Preparación de una prueba piloto. El firmware aún no está instalado.**

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Un Echo Dot 2 está disponible mediante EchoMuse/emOS; el segundo está desconectado. Aún no hay acceso USB de mantenimiento. No se modificaron Home Assistant ni el firmware activo. Versión objetivo: **TECHO5 Dot v1.0.34**.

El modelo actual de «Привет, Мышка» usa ONNX y no se puede copiar directamente a microWakeWord. Las antiguas copias completas de Alexa se eliminaron deliberadamente. Antes de la prueba hay que confirmar una migración compatible y los archivos de recuperación necesarios para ese método.

Guías detalladas, actualmente en inglés: [estado](docs/status.md), [migración](docs/migration.md), [palabra de activación](docs/wake-word.md), [Home Assistant](docs/home-assistant.md), [aceptación](docs/acceptance.md).
