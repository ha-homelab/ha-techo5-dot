# HA · TECHO5 Dot

**Préparation d'un pilote. Aucun nouveau firmware n'est installé.**

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Un Echo Dot 2 est accessible via EchoMuse/emOS ; le second est hors ligne. L'accès USB de maintenance n'est pas disponible. Home Assistant et le firmware actif n'ont pas été modifiés. Version cible : **TECHO5 Dot v1.0.34**.

Le modèle actuel de «Привет, Мышка» utilise ONNX et ne peut pas être copié directement dans microWakeWord. Les anciennes sauvegardes complètes d'Alexa ont été supprimées volontairement. Avant le pilote, il faut confirmer une migration prise en charge et les fichiers de récupération nécessaires à cette méthode.

Guides détaillés, actuellement en anglais : [état](docs/status.md), [migration](docs/migration.md), [mot d'activation](docs/wake-word.md), [Home Assistant](docs/home-assistant.md), [validation](docs/acceptance.md).
